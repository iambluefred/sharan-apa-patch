1. 樣本與位址

上游以 HCA 連續工作 360 秒、中斷 3 秒、恢復後工作 300 秒的現象為搜尋線索。兩份原始 SGO 各為 272,694 bytes；上游稱其檔案偏移 0x31 的識別字串經 XOR 0xFF 可讀為相應的 5N1909144R_1401_BP.sgm 與 5N1909144S_1501_BP.sgm。

候選用途u16 數值R 的 Flash 位址S 的 Flash 位址相對錨點
360 秒工作期36000／0x8CA00x0360F80x036170+0x000
300 秒恢復期30000／0x75300x0361020x03617A+0x00A
3 秒中斷期300／0x012C0x0362120x03628A+0x11A

10 ms tick 的換算為：秒數 = 數值 ÷ 100。u16 LE 指低位元組在前，例如 300 的解碼後位元組為 2C 01。若所在資料塊使用 XOR 0xFF 編碼，其儲存內容會取反；不應直接在整個 SGO 用解碼值搜尋後改寫。

2. 作者提出的五條定位線索

  1. 唯一性：R 映像中的 36000 僅出現一次；30000 出現四次，其中一處位於相同候選常數區。
  2. 單位一致：附近有 100、300、500、1500、2000、3000、5000、6000、7000、10000、15000、18700、25000、30000、32000、36000、44000 等數值，作者將其解釋為共同採用 10 ms tick 的時間參數。
  3. 跨版本布局：R_1401、S_1501 與 N_1101 中，三個目標數值相對 36000 的偏移相同。N 樣本未包含在公開倉庫。
  4. 局部區域一致：以錨點為準的 -0x320 … +0x1E0 共 1280-byte 視窗，作者報告 R 與 S 完全相同，R 與 N 約有 6% 差異。
  5. 區分標量與曲線：作者認為 +0x11A 的 300 是兩段下降數列間的獨立值；另一處 +0x1C2 的 300 在 N 版本變為 10486，因此被判為曲線點而排除。

上述線索支持「候選位置」，但沒有提供該位置被 HCA 計時邏輯讀取的程式交叉引用，也沒有在本倉庫給出完整測試紀錄。這份繁體中文整理保留這個不確定性。

3. 作者記錄的 R／S 區塊差異

區塊起始位址上游比較結果
blk0：0x05F000相同
blk1：0x004000184,067 個位元組不同，分為 138 個差異群
blk2：0x804200341 個位元組不同；作者另列出的 93 筆參數紀錄相同
blk3：0x60C000相同
其他小區塊相同

作者據此推測軟體代際主要改變成片的資料表，而候選時間常數區保持固定。只比較差異分布，本身仍不足以證明每一個區塊的資料／程式屬性。

4. 修改內容與檔案偏移

四份 SGO 都是上游已生成的檔案：R／S 各有將候選 300 改為 1 與改為 0 的版本。本機未重新製作或改動補丁。

版本Flash 位址上游提及的 SGO 資料偏移修改值
R_1401_BP0x0362120x32A8C 附近300 → 1 或 0
S_1501_BP0x03628A0x32B04 附近300 → 1 或 0

上游稱修改範圍僅包含目標兩個位元組與對應校驗，並提及 blk1 校驗偏移 0x874／0x875。原始檔位於 originals/R 與 originals/S。

5. SGO 編碼與校驗的已知範圍

論壇說明資料塊使用逐位元組 XOR 0xFF。上游首頁將塊校驗描述為 sum(塊體) & 0xFFFF，檔案校驗描述為 sum(全檔案) - 1；詳細文件聲稱四份補丁均得到檔案校驗與 8/8 區塊校驗通過。

這些文字沒有完整定義欄位位置、校驗位元組是否排除、長度與儲存端序等實作細節。因此不能只憑這兩個算式就宣稱已重現 SGO 工具。文件引用的 work/scripts/sgo_tool.py patch --flash … --u16 … 沒有包含在這份公開倉庫中。

6. 延長其他候選時間的上游討論

上游提到將 36000 改為 u16 上限 0xFFFF，按 10 ms tick 解釋為 655.35 秒；亦提到可增大 30000。這些是研究方向，並未附經驗證的新檔案。作者不建議把這兩個工作期數值改為零，因其可能立即觸發狀態轉換。

7. 如何判讀驗證結果

上游建議先比較縮短為 0.01 秒的版本，觀察 HCA 持續工作後的週期性中斷是否變短，另將零秒版作為比較。若兩者均無效，作者承認可能找錯常數，需取得 ECU 程式映像追蹤實際讀取位置。

本機整理未執行該測試。檔案完整性、SGO 校驗、刷寫能否成功，以及 HCA 實際行為，應視為四個不同驗證項目。不能把校驗成功描述成「已解鎖」或「已證明可無限工作」。
