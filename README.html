這個專案在研究什麼

上游描述的 HCA 行為是：持續接受車道保持扭矩疊加約 360 秒後，中斷約 3 秒，再恢復約 300 秒。作者嘗試在既有 SGO 中定位對應計時常數，以修改標定的方式縮短中斷。

上游詳細 README 明確保留一項限制：沒有 ECU 程式碼，無法完全證明 HCA 狀態機讀取的就是這個參數。檔案校驗通過與實際效果成立，是兩件需要分別驗證的事。這次僅下載及整理文件，沒有連接車輛或執行刷寫。

文中的「鎖定／失效」是作者對 HCA 輔助功能中斷的描述；不能由文章推定整個機械轉向鎖住或一般轉向助力全部消失。
